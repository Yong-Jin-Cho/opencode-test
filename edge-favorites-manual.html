2장. 목표 구조 — 8폴더로 통일

원칙: 같은 카테고리는 하나의 폴더. 번호를 앞에 붙이면 순서가 고정됩니다.

01_자주씀

매일 여는 10개 이내만. 북마크바에 표시. 네이버·유튜브·지메일·캘린더 등.

02_학습·교육

삼성교육·OPIc·TOEIC·파이썬·주기율표. 기존 01 Edu + 흩어진 교육 링크 통합.

03_업무·기술

SETC 2개 → 1개로 통합. 하위는 모터/회로/펌프/체결/화학 유지. 사내 시스템은 하위폴더 _사내_보관.

04_금융·쇼핑

뱅킹 + 쇼핑 통합. 기존 뱅킹·쇼핑·IE쇼핑 3곳 → 1곳. 하위: 금융 / 쇼핑 / 여행·예매.

05_취미·영상

스키·게임(D4/POE2)·그림(CLIP)·유튜브 35개 통합. 하위: 스키 / 게임 / 그림 / 보기나중에.

06_AI·도구

ChatGPT·Gemini·NotebookLM·Copilot·AI Studio·번역기. 새로 만드는 폴더.

07_읽을거리

블로그·뉴스·커뮤니티(루리·인벤·디시). 하위 없이 20개 이내 유지.

08_보관함

IE유물·사내망·빈제목·http 구형. 지우기 전 1개월 보관. 하위: _IE옛자료 / _사내_보관 / _확인필요.

5장. 유지관리 3원칙 + 인쇄

① 들어오면 바로 분류

새 즐겨찾기는 저장 대화상자에서 폴더를 지정. “북마크바(뿌리)”에 그냥 저장 금지.

② 월 1회 5분 청소

관리자 검색 → http:// 입력해 https로 교체, 안 열리는 것은 삭제. 01_자주씀은 10개 유지.

③ 08_보관함 비우기

1개월 안 쓴 것은 삭제. Edge 동기화(프로필 로그인)를 켜면 PC·모바일이 함께 정리됩니다.

인쇄 팁: 여백 보통, 배경 그래픽 끄기. 1~5장이 모두 출력됩니다.
